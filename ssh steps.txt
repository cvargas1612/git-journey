1. Verificar si ya existe una llave SSH

En la terminal:

ls -al ~/.ssh


Si existen archivos como id_ed25519 y id_ed25519.pub, ya hay una llave creada.
Si no existen, continúa con el paso 2.

2. Crear una nueva llave SSH
ssh-keygen -t ed25519 -C "tu_email_de_github"


Cuando aparezcan los mensajes:

Ruta del archivo: presionar ENTER (usar la ruta por defecto)

Passphrase: escribir una frase corta (recomendado)

Confirmar passphrase: repetir la frase

Esto crea:

Llave privada: ~/.ssh/id_ed25519

Llave pública: ~/.ssh/id_ed25519.pub

3. Iniciar el agente SSH y añadir la llave
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519


Introduce la passphrase cuando se solicite.

Verificar que la llave está cargada:

ssh-add -l

4. Copiar la llave pública
cat ~/.ssh/id_ed25519.pub


Copiar todo el contenido que se muestra.

5. Añadir la llave SSH a GitHub

Entrar a GitHub en el navegador

Ir a Settings

Seleccionar SSH and GPG keys

Click en New SSH key

Pegar la llave pública copiada

Guardar

6. Probar la conexión con GitHub
ssh -T git@github.com


Salida esperada:

Hi TU_USUARIO! You've successfully authenticated, but GitHub does not provide shell access.


Esto confirma que la conexión SSH funciona correctamente.

7. Clonar un repositorio usando SSH

Desde GitHub (web):

Entrar al repositorio

Click en Code

Seleccionar SSH

Copiar la URL con formato:

git@github.com:usuario/repositorio.git


En la terminal:

git clone git@github.com:usuario/repositorio.git

8. Subir cambios a GitHub (flujo básico)

Dentro del repositorio clonado:

git status
git add .
git commit -m "Mensaje descriptivo del cambio"
git push


Si es la primera vez en la rama principal:

git push -u origin main

9. Verificar que el repositorio usa SSH
git remote -v


Debe mostrar URLs que comiencen con:

git@github.com:


Si aparece https://, se puede corregir con:

git remote set-url origin git@github.com:usuario/repositorio.git
